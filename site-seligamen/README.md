# SE LIGA, MEN! — Landing Page

Página pública para `seligamen.agenciasitelab.com.br`.

## Configuração dos links
Edite `config.js` e preencha:
- `whatsappGroupUrl`
- `instagramUrl`
- `tiktokUrl`

## Vercel
Use este diretório como **Root Directory** de um projeto Vercel separado: `site-seligamen`.
Framework preset: **Other**. Não precisa de build command.
